# Independent C64 BASIC starter prefix

`c64-sys-2061.hex` is the complete PRG emitted by VICE 3.10 petcat for a
single BASIC line, without assembly or machine-code bytes:

```sh
printf '10sys2061\n' | petcat -w2 -o native.prg
python3 -c 'from pathlib import Path; print(Path("native.prg").read_bytes().hex())'
```

The retained prefix includes the two-byte PRG load address. Regression tests
append the original border program's instruction bytes; the parsed SYS target
must equal their actual starting address. Mutating the next-line pointer to
the original faulty value must fail. This fixture requires no installed VICE
in CI and contains no firmware.
