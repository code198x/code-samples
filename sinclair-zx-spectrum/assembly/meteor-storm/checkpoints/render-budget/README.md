# Save drawing work without losing contacts

Grow each record from five to seven bytes: previous image X and Y are appended. Keep the old image during the first boosted physics step. Erase that image and redraw once on the second. An object removed in the first step must erase immediately. Spawned objects need valid previous-image coordinates. Compare cadence with boost; both collision checks remain.

Predict, then check: on the same boosted route `frame_delta` now reads only 1 and 2, while every collision is still checked on both steps.

Space launches; O/P steer; hold Space for 2X, release for 1X. One hit ends the run. R retries a result; Q returns to the title, in flight or at a result.

Repeat: R at a result starts the same run again from a cleared state; Q then Space starts it from the title.

This is a complete program, not a fragment to paste into an unseen engine. See
the [module build instructions](../../README.md) and [routine contracts](../../contracts.md).
