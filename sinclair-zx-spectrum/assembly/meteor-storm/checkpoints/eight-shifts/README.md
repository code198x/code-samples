# Prepare all eight offsets

Read each pair in rows before running. Offset seven should be $01,$02. Eight scanlines now show the same two pixels at successive horizontal positions. These are data on the target; generating them on the host does not make the Z80 faster at shifting.

No keys. Reload or reset to repeat.
