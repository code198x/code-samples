# Meet BASIC: movement

Units 12–15 develop position, animation, keyboard polling, boundaries and one press per step.

Each numbered step is a complete Sinclair BASIC program for a 48K ZX Spectrum.
Start this project with an empty program; follow the companion lesson for changes
between steps. [Execution evidence and reproduction](../completion-verification/README.md)
cover all checkpoints and a named tape load into a fresh emulator process.
