# Integer-enlarged glyph caller

See the [shared contract](../../../../../cross-platform/patterns/rendering/scaled-text/README.md).

`demo.asm` configures this machine’s named reset/display fixture, includes the existing backend and original font, then calls the reusable component through `prepare.inc`. `customise.asm` changes the scale and counted message. Keep both scale inputs and the native byte order explicit. The diagnostic mailbox is verification transport, not a required game structure.
