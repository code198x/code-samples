# Glyph transforms: amstrad-cpc

Complete original reset caller for the shared [glyph transform component](../../../../../cross-platform/patterns/rendering/glyph-transform/README.md).

`make` builds normal clockwise and customised reflected F demonstrations with Asm198x. `prepare.inc` shows the include/init/call contract; `caller.inc` owns this machine's display setup and the existing scaled-text backend. Verification uses a mailbox, not a game-loop prescription.

Read the shared contract for scratch, bounds, overlap, clobbers, resource ownership, costs, wrong/fixed examples and exact configuration limits. Run fresh native qualification from the repository root with `--only amstrad-cpc`; `verification/results.json` retains source/tool hashes and observed glyph/frame data.
