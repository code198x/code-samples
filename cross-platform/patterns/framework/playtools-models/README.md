# Independent movement, interaction and data contracts

These integer/list/polynomial models provide verification inputs and expected results for ten native topics. They are not a runtime library or new project-wide asset format. Each named configuration has 64 boundary/varied/error cases and a separate sequential caller. The explicit scripts/playtools-targets.json inventory names delivered machine implementations; missing records fail the gate. Intermediate PRs carry only the target layers they deliver.

Native byte arithmetic is independent of the integer/list calculations. All four core configurations execute init, correct/custom clients, deliberate caller mistakes and exact repairs. Code and caller-owned immutable data are checked separately from writable state and diagnostic storage. Public CI checks retained native observations and rejection controls; restricted-firmware execution is qualified locally and is not silently replaced by a host test.
