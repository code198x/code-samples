# Pattern Library routine audit — 19 October 2026

We found and fixed real defects. This is a review of all 83 entries and their maintained-source closure, including the five draft compositions. It is not a claim that every illustrative listing has become a tested reusable implementation.

## What now has fresh execution evidence

- Six Z80 groups: 32 input masks, 772 character/string cases, five attribute footprints, four masked-sprite boundary cases, 1,300 numeric/BCD cases and 25 animation phases/page crossings.
- NES movement: 3,984 actual CPU position/input cases against inclusive saturation.
- Amiga: eight actual blitter octants, a complete four-voice sequencer with observed Paula state and stereo PCM, and all 1,024 synthetic edge/history transitions.
- Spectrum BASIC: four ROM-loaded display helpers, ten digit masks and nine progress values; odd-length text now uses explicit floor centring.
- Complete Spectrum title/play/pause/game-over caller with real keys; C64 eight-step scroll with all 1,000 characters and colour nibbles. C64 colour observations are copied by the guest CPU because debugger raw-memory reads do not represent colour I/O.

Old broken Z80 routines, incorrect line geometry, DMA-disabled audio, unclamped NES movement, fractional BASIC centring, incomplete C64 coarse scrolling and a broken edge predicate were rejected by behavioural observers. Deliberately altered/empty/missing audit inputs are also rejected. The eight current execution records bind31 source/observer inputs; that guard checks retention, not runtime behaviour.

## Scope and limits

Inputs: samples base `e8e445b7d51e7292edb1a8503db467f032a1fee1`; website base `82ace206cb62419bb51a02c65a1eecf716586b90`. The accompanying `inventory.json` pins every reviewed page and referenced source. Behaviour records contain their exact observer/source/tool hashes. Historical versions remain in Git history; do not refresh a record hash without rerunning its fixture.

The 30-system capability inventory still passes registry membership, complete source/evidence/capture checks and negative controls. It contains five compositions and 25 additional probes; audio executed on 28systems, while stock ZX80/ZX81 have no speaker. These are retained results, not a new thirty-emulator replay. BBC Micro coverage is retained from the draft tranche; it was not silently inferred from another 6502 machine.

Every illustrative entry below still needs its own complete caller and execution matrix before it can carry a runtime-qualified claim. In particular: NES PPU upload/split and music integration; Amiga Copper/sprite/blit and interrupt adapters; C64 SID sequencing; Spectrum AY/beeper music. Boundary, timing, DMA and interrupt coexistence cannot be certified by prose review or successful assembly. Low-level contracts are clearer, but beginner usability still benefits from someone following the instructions in a fresh project.

The first state-machine assembly probe disproved a suspected out-of-range JR: the old listing assembled. Its actual problems were empty input/update hooks and missing pause transitions. The report does not present that hypothesis as a confirmed bug.

Private firmware and emulator snapshots are excluded from review bundles. Reproduce ROM/ADF checks with your own configured firmware. No dependency, route, schema or binding project policy changed. Nothing was merged or deployed by this audit.

## Reproduce

Use the eight `scripts/verify-*.py` observers selected in `scripts/routine-audit-evidence.json`; their `--help` describes tool/output arguments. For firmware-free CPU fixtures, run `verify-z80-library-routines.py` and `verify-nes-movement.py` with the recorded Asm198x/Emu198x tool pair. BASIC/Amiga and ROM-loaded callers require the named firmware. Keep negative mutations in isolated source copies and restore the verified source before any hash check.

```sh
python scripts/check-pattern-evidence.py --audit
python -m unittest discover -s scripts -p test_routine_audit.py -v
python scripts/check-capability-coverage.py
python scripts/audit-pattern-library.py --website ../website --output /tmp/pattern-inventory.json
```
